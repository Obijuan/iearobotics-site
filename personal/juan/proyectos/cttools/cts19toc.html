NAME

cts19toc - Conversión de código s19 en matrices C

SYNOPSIS

cts19toc fichero.s19 [-h]

DESCRIPTION

Programa para tomar la parte del código de la ram interna de un fichero .S19 y generar una matriz en C con los 256 bytes. El fichero generado es el mismo que el pasado como argumento pero se le añade ".c" al final.

ARGUMENTOS

[-h]
mostrar ayuda adicional

EJEMPLO

cts19toc ledp.s19
