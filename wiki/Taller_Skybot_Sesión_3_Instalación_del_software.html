Introducción

Para programar el Skybot necesitamos las siguientes herramientas:

  • SDCC. Compilador de C para microcontroladores PIC
  • GPUTILS. Utilidades para los microcontroladores PIC
  • Pydownloader. Descarga de programas en la tarjeta Skypic:
  • Skybot-test. Programa de diagnósticos para el Skybot
  • Editor de textos o entorno de programación. Necesario para escribir los programas en C para el Skybot

Instalando el software

Windows XP y Windows 7

La instalación es la misma para ambos sitemas. Recomendamos instalar como Administrador y para todos los usuarios.

  • SDCC para Windows: SDCC-2.9.0-setup.zip. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto. En la última pantalla de la instalación, recomendamos aceptar la modiciación del PATH para todos los usuarios.


  • GPUTILS: Gputils-0.13.7.zip. Descargar, unzip y ejecutar el .EXE aceptando configuraciones por defecto. En la última pantalla de la instalación, recomendamos aceptar la modiciación del PATH para todos los usuarios.


  • MAKE (opcional): Make.zip. Descomprir los archivos del ZIP en la carpeta "<Mi_Directorio>/SDCC/bin/" de esa forma las utilizades estarán en el PATH. <Mi_directorio> se corresponde con el lugar escogido por nosotros durante la instalación del SDCC. Si no se cambió nada durante la instalación del SDCC entonces lo más probable es que el lugar sea "c:\archivos de programa\sdcc". También se puede usar el buscador de Windows para ver en que lugar se ha instalado el compilador.


  • Programers Notepad: Pn208718.zip. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto. El Programmer's Notepad es un editor al cual se le pueden añadir herramientas externas. Nosotros añadiremos el SDCC para poder compilar desde el editor directamente. ...Opciones de la herramienta

Ahora vamos a instalar las herramientas desarrolladas espercíficamente para la Skypic y el Skybot. Estan programadas en Python y son multiplataforma.

  • python-2.5.msi: python-2.5.msi.Instalar Python para Windows.Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • pywin32-210.win32-py2.5.zip: 2-pywin32-210.win32-py2.5.zip. Instalar las extensiones del Python. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • pyserial-2.2.win32.zip: 3-pyserial-2.2.win32.zip. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • libstargate-1.2.win32.zip:4-libstargate-1.2.win32.zip.Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • libIris-1.2.win32.zip : 5-libIris-1.2.win32.zip 5-libIris-1.2.win32.zip. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • pydownloader-wx-1.0.win32.zip : 6-pydownloader-wx-1.0.win32.zip . Descarga de programas en la tarjeta Skypic. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • pyburn-wx-1.0.win32.zip :pyburn-wx-1.0.win32.exe. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • wxPython2.8-win32-unicode-2.8.6.0-py25.zip :wxPython2.8-win32-unicode-2.8.6.0-py25.exe. Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.
  • skybot-test-1.0.1.win32.zip : 9-skybot-test-1.0.1.win32.zip. Programa de diagnósticos para el Skybot . Descargar, unzip y ejecutar el .EXE aceptando la configuraciones por defecto.

Los programas de python pydownloader, skybot-test y pyburn se encuentran en el directorio de Python en la carpeta Scripts. Si no se ha modificado la ruta de instalación el directorio es C:\python\scripts. Para facilitar el uso se pueden copiar al escritorio.
