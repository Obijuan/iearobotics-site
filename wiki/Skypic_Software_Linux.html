Herramientas

  • Descarga de programas en la Skypic: Pydownloader
  • Entorno de desarrollo integrado (IDE): Piklab
  • Herramientas de desarrollo para PIC: Gputils
  • Compilador de C: SDCC

Instalación

Ubuntu 10.10

  • Paquete sdcc. Compilador de C (Instalar)
Instalación manual: sudo apt-get install sdcc gputils

Arquitectura i386 (32-bits)

  • Paquete libiris: python-libiris_1.2-5_i386-ubuntu-10.04.deb
  • Paquete libStargate: python-libstargate_1.2-1_i386-ubuntu-10.04.deb
  • Paquete pydownloader: pydownloader-wx_1.0-2_i386-ubuntu-10.04.deb

Arquitectura x86 (64-bits)

  • Paquete libiris: python-libiris_1.2-5_amd64-ubuntu-10.10.deb
  • Paquete libStargate: python-libstargate_1.2-1_amd64.deb
  • Paquete pydownloader: pydownloader-wx_1.0-2_amd64.deb

Ubuntu 10.04

  • Instalar el compilador de c: SDCC (Instalar) (apt-url)
  • Instalar la librería libiris: python-libiris_1.2-5_i386-ubuntu-10.04.deb
  • Instalar el pydownloader: pydownloader-wx_1.0-2_i386-ubuntu-10.04.deb

Ubuntu 9.04

  • Instalar el compilador de c: SDCC
  • Instalar la librería libiris: python-libiris_1.2-5_i386-ubuntu-9-04.deb
  • Instalar el pydownloader: pydownloader-wx_1.0-2_i386-ubuntu-9-04.deb


Ubuntu 7.10

  • Instalar el ensamblador y compilador de c:
 sudo apt-get install gputils sdcc
  • Instalar paquete LibIris (Pinchar y abrir con GDebi)
  • Instalar paquete LibStargate (Pinchar y abrir con GDebi)
  • Instalar paquete Pydownloader (Pichar y abrir con GDebi)

Por hacer: Instalar piklab
