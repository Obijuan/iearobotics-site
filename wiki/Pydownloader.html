Introducción

Pydownloader es una aplicación para descarga de programas en la Skypic. Es necesario previamente que el bootloader se encuentre ya grabado en la Skypic. Con el Pydownloader se puede:

  • Descargar ficheros .hex
  • Descargar directamente los servidores del proyecto Stargate
  • Descargar directamente el programa de pruebas ledp para hacer comprobaciones rápidas de la Skypic

El Pydownloader está basado en la LibIris

Sabores

El Pydownloader está disponible en cuatro "sabores":

  • Pydownloader-console: Versión para la consola. Linux/FreeBSD/Windows.
  • Pydownloader-wx: Interfaz gráfica usando las librerías Wxpython. Linux/Windows
  • Pydownloader-gtk: Interfaz gráfica usando las PyGTK. Linux
  • Pydownloader-qt: Interfaz gráfica usando las PyQT. Linux
