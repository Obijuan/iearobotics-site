Introducción

El programa skypic-test permite realizar una prueba rápida de la Skypic. Se descarga un programa que hace que el led parpadee. Así se puede comprobar rápidamente si la Skypic está funcionando o si tiene el Bootloader correctamente grabado

Características

  • Lenguaje de programación: Python
  • Sistema operativo: Multiplataforma (Linux/Windows)
  • Interfaz usuario: Consola
  • Licencia: GPL

Autores

  • Rafael Treviño,
  • Juan González

Utilización

Parámetros

Se invoca de la siguiente forma: 

python skypic-test <serie>

donde los parámetros son:

  • <serie>: Nombre del dispositivo serie a emplear.
    • En plataformas Windows será COM1, COM2...
    • En Linux: /dev/ttyS0, /dev/ttyUSB0...

Ejemplos

En este ejemplo se prueba una Skypic conectada a un conversor USB-serie en una máquina Linux. El dispositivo serie usado es el /dev/ttyUSB0. Según cómo se tenga conectado el jumper JP4, el reset de la Skypic habrá que realizarlo manualmente o será automático. En caso de reset manual, el programa se quedará esperando a que se pulse el reset indicando el mensaje "Esperando Bootloader" 

$ python skypic-test /dev/ttyUSB0 

Skypic-test. Prueba rapida de la Skypic. Licencia GPL 

Serial port /dev/ttyUSB0 opened.
Reset Skypic
Esperando Bootloader
.............Bootloader OK 

Descargando:
*** OK
Ejecutando programa

Su uso en Windows es similar. Lo que cambia es el nombre del dispositivo serie. En este ejemplo es el COM1: 

> python skypic-test COM1

Serial port COM1 opened.
Reset Skypic

.............Bootloader OK 

Descargando:
*** OK
Ejecutando programa
