Introducción

El programa PIC_downloader es una aplicación para LINUX para descargar programas en la tarjeta Skypic. Es necesario que en ella esté grabado previamente el PIC_Bootloader.

Características

  • Interfaz en línea de comando
  • Funciona con puerto serie o conversores USB-serie
  • Lenguaje: C
  • Descarga automática sin necesidad de apretar el botón de reset de la Skypic. (Jumper JP4 en posición DTR)

Ejemplo de funcionamiento

En este ejemplo la Skypic está conectada al PC mediante un conversor USB-serie. El programa que se quiere descargar es el ledp.hex. Si el jumper JP4 está entre las posiciones 2 y 3 la descarga comenzará automáticamente: 

$ ./PIC_downloader ledp.hex -P/dev/ttyUSB0
PIC_downloader 1.2. Descarga de programas en la tarjeta Skypic
Licencia GPL 

Fichero: ledp.hex
Puerto serie: /dev/ttyUSB0 

Esperando conexion:  - OK
Writing:  - OK
Activating program... - OK

Si el jumper JP4 está entre las posiciones 1 y 2 el cargador se quedará esperando hasta que se pulse el botón de reset: 

$ ./PIC_downloader ledp.hex -P/dev/ttyUSB0
 PIC_downloader 1.2. Descarga de programas en la tarjeta Skypic
 Licencia GPL 

 Fichero: ledp.hex
 Puerto serie: /dev/ttyUSB0  

 Esperando conexion: .......................

Cuando se apriete el reset el programa se descargará: 

 Writing:  - OK
 Activating program... - OK
