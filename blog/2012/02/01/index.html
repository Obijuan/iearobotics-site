Clone wars: Prusa Mold (I)

Cesar Augusto Fernández ha propuesto hacer, para el proyecto Clone wars, moldes de silicona para hacer las piezas rápidamente. Yo era una técnica que desconocía, pero César me ha convencido 🙂 Creo que tiene mucho ponencial. Así es como ha nacido la Prusa Mold, construir una Prusa mediante moldes.

El pasado martes 31 de Enero, quedamos Fernando Salceda, César y yo en el Medialab Prado para hacer pruebas. César me había mandado un fichero STL para hacer una pieza de la que sacar el molde. La imprimí en R2D2:

El siguiente paso es echar la silicona en la pieza para obtener el molde. Desafortunadamente no había silicona suficiente, por lo que César improvisó una barrera de plastilina para sólo llenar de silicona la mitad. Una vez que la silicona está en la pieza, hay que esperar 24h para tener el molde.

Este viernes (3 de Febrero) volveremos a quedar en el MediaLab para ver el resultado del molde. Mientras tanto aprovechamos para hacer otras piezas a partir de moldes que César ya tenía hechos. En este post no entraré en detalles, sólo quiero comentarlo para que os hagáis una idea de cómo es el proceso. Hay que verter la resina de poliuretano (obtenida mediante la mezcla de dos componentes) en el molde.

La resina solidifica en unos 10 minutos. Se puede apreciar cómo va cambiando de color marrón a blanco. Transcurrido ese tiempo, se pueden sacar las piezas y quitar los pasantes de silicona usados para hacer los taladros.

El proceso se repite varias veces para obtener las piezas necesarias. ¡Las piezas salen como churros! En esta foto se pueden ver algunas de las piezas sacadas para montar el Clon Leia de César:

Y con esto nos despedimos. Aquí estamos los aventureros en el MediaLab, con la mesa totalmente tomada por los productos químicos y las piezas.
